# Lendas de Aço (versão web)

Jogo de ação 2D offline feito em Godot 4.3. Esta pasta já está pronta para o GitHub Pages:
a cada envio para a branch `main`, o GitHub exporta o jogo sozinho e publica o site.

## Publicar (versão com todos os arquivos na raiz, sem pastas)
1. Crie um repositório novo no GitHub (pode ser público).
2. Envie TODOS os arquivos desta pasta, incluindo a pasta oculta `.github`.
3. No repositório: Settings > Pages > Source: escolha **GitHub Actions**.
4. Abra a aba **Actions** e espere o fluxo "Publicar no GitHub Pages" ficar verde (2 a 4 minutos).
5. O endereço do jogo será https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/

## No iPhone
Abra o endereço no Safari, gire o aparelho para deitado, toque em Compartilhar > Adicionar à Tela de Início.

## No computador
Teclado: A/D mover, Espaço pular, J atacar, K/L/; habilidades, Shift esquiva.
O progresso fica salvo no navegador. Limpar os dados do site apaga o save.

## Rodar no Godot
Abra `project.godot` no Godot 4.3 ou mais novo e aperte F5.
